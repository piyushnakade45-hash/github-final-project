# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Ways to Contribute

- **Bug reports:** open an issue describing the problem, the steps to reproduce it, and what you expected to happen.
- **Bug fixes:** fix an existing issue and submit a pull request.
- **Documentation improvements:** fix typos, clarify instructions, or add examples.
- **Enhancements:** suggest or add new features to the calculator.
- **Ideas:** open an issue to start a discussion.

## How to Contribute

1. Fork the repository.
2. Clone your fork to your computer:
   ```bash
   git clone https://github.com/<your-username>/simple-interest-calculator.git
   ```
3. Create a new branch for your change:
   ```bash
   git checkout -b my-change
   ```
4. Make your changes and commit them:
   ```bash
   git add .
   git commit -m "Describe your change"
   ```
5. Push the branch to your fork:
   ```bash
   git push origin my-change
   ```
6. Open a pull request against the `main` branch.

## Guidelines

- Keep changes small and focused.
- Test the script before submitting (`./simple-interest.sh`).
- Be respectful to other contributors. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
